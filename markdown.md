## 🙋🏻‍♀️ About Me

- 안녕하세요! 새로운 도전을 즐기며 꾸준히 성장하는 백엔드 개발자 양혜지입니다.
- Spring 생태계 기반의 프로젝트 경험과 문제 해결 능력을 바탕으로 성능 최적화와 안정적인 서비스 구현에 집중해왔습니다.
- 사용자 중심의 API 설계와 지속적인 학습을 통해 더 나은 서비스를 만드는 개발자가 되고자 합니다.
